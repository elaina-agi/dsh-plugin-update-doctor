# v0.6.5：去掉确认弹窗勾选框，检查加真实进度条

两件事，都是你在真实面板里提的。

## 1. 确认弹窗只剩「选择 + 确认 / 取消」

删掉两个勾选框及其文案：

- 公共镜像 / 公共备用源来源确认；
- 完整依赖代际（Union 等）的本地归档来源确认。

来源迁移的说明也改成纯提示。现在弹窗里只有：插件与版本列表、影响说明、「更新前任务处理」（等待 / 停止当前任务）两个选项、底部「取消 / 确认」。

风险说明照旧显示，但不再要求逐项勾选。服务端的显式确认没有放宽：`commitBatch` 仍要求 `confirmUnionGeneration` / `confirmPublicMirror` / `confirmMigration` 为真；面板在对应计划上自动附带这些标志，等于把「用户逐项勾选」改成「面板按已展示的计划自动声明」——风险文字还在，只是不再挡操作。

## 2. 检查进度条

「检查全部更新」现在有真实进度，而不是一个转圈：

- 阶段：查询发布版本 → 逐个核对更新包 → 完成；
- 显示当前正在检查的插件、已完成 / 总数、百分比；
- 进度来自 Host 的真实检查过程（`progressId` + `scan-progress` 轮询，1.2 秒一次），不是假动画；
- 完成后显示「检查完成」并自动收起；
- 检查请求超时从 180 秒放宽到 300 秒，慢网络下不会在中途被前端掐断。

## 验证

- 回归 **433 项通过**（Node 24 串行）。
- 服务端：检查期间可读到 `phase/current/done/total`，完成后 `phase=complete`、`done=total`；未知 id 返回 400；进度不含 profile 路径。
- 面板：确认弹窗中不再有 `type=checkbox`；迁移 / 镜像 / 代际三个场景点确认时自动带上对应标志；进度条有 `progressbar` 语义与独立样式。
- 打包冒烟通过（自有临时 profile 启动、Host 激活、Client 资源、原生助手）。

## 限制

- 进度只反映面板自己的检查；官方管理器后台操作没有进度上报。
- 浏览器视觉、键盘与窄屏仍未真实验收；进度条的动画效果只能由 CSS 断言，不能代替截图。
