# v0.5.5：普通插件镜像下载与更新预检

- **普通镜像下载**：普通 npm 插件预检也支持 npmmirror 的固定 CDN 单跳，只接受精确包名和版本的路径。继续核验 SRI、运行声明和官方 npm 同版本摘要；不放开任意重定向，不改全局源。
- **先核验再允许勾选**：发现新版不等于可在线替换。普通候选通过只读的新旧原包、已装文件及当前依赖检查后才可勾选。扫描不写入暂存包或确认票据；准备时只重查所选插件，执行前仍复验。下载或校验失败会保留版本发现结果，并给出具体原因。
- **Better Sidebar**：仅支持经审查的 npm `0.32.1 → 0.33.0` 原包对。新版将已打入客户端的库移出运行依赖，Host 仍使用相同 `ws`／`yaml` 闭包。仅认可这对原包里字节固定的动态停用声明；预检不执行该表达式。替换前后核验保留依赖的实际版本和文件，拒绝可解析的 `ws` 原生加速包，不自动批准脚本。其他变更不继承准入。

正常更新仍由 DSH 官方插件管理器按精确 npm 版本执行，保留 npm 安装来源及官方版本检查资格。更新失败与恢复分别记录。宿主会重新下载；预检不是原子替换或安装相同归档字节的保证。自身升级、WSL 和 Union Search 的独立路线及未知结果保护不变。

验证范围见[验证记录](<VERIFICATION.md>)。隔离 Host 与真实镜像只读校验证据不等于用户实际安装、浏览器渲染或正在运行的任务连续性验收。
