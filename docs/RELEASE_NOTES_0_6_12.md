# v0.6.12：面板直接标出「宿主包依赖」

按你的要求，把 `hostDependencies` 从「只在计划和报告里」搬到面板行上。

## 显示方式

- **行内徽标**：插件把 `@deepseek-ai/*` 写成普通依赖时，状态旁出现 `⚠ 宿主包依赖`；
- **详情展开**：列出具体是哪些包，并说明后果——包管理器可能把它装到 profile 根部，宿主可能因此停用对应的核心行；
- **明确不拦**：文案最后一句是「更新仍会照常尝试」，行仍然可选、可更新。

没有这种依赖的插件完全不显示，行上不会多一个字。

## 为什么值得显示

上一轮 20 款里，`dsh-file-bookmark` 就是把 `@deepseek-ai/dsh-tools@0.1.7-rc.2` 写成普通依赖，结果 pnpm 把它装到 profile 根部、DSH 停用了核心 `tools` 行，它自己卡在 `pending (waiting for service: tools)`。现在这类插件在点击更新之前就能看到原因。

- 只显示目标包**声明**的宿主依赖；宿主行是否真的被停用仍以 DSH 自己的日志与我们的装后核验为准。
- 浏览器渲染仍未人工验收（本地无浏览器控制）。
