# v0.5.1 更新说明（发布前草稿）

> **历史快照：本页保留0.5.1打包/审查当时的状态，不是当前0.5.3的支持清单或待办。** 用户后来另行安装更新器0.5.3并确认WSL0.26.2→0.29.0升级成功；Union新增受限代际路线和WSL结构准入请以[当前验证记录](<VERIFICATION.md>)、[Windows支持](<WINDOWS_SUPPORT.md>)为准。下方旧限制和计数不改写为最新代码已复验，公共新版npm仍未发布。

> **状态：尚未发布、尚未在用户环境／浏览器验收。** 当前公共 npm 版本仍为 v0.5.0。本页介绍本地 v0.5.1 开发稿，不代表现有用户已经获得这些修复；候选安装包资源及隔离原版Host验收已做，真实DSH界面和公开旧版升级仍待验收。

## 这次改了什么

### 版本检查更准确

- 修复 WSL 等插件的新版信息因 npm 精简元数据被遗漏，导致误报“没有新版”的问题。
- 将“发现新版”和“能否在线更新”分开显示，并标明实际查询源。镜像没有查到新版，不代表所有来源都没有新版。
- 查询失败、元数据不完整、版本窗口有遗漏时，不再显示成“已是最新”。

### 普通 npm 更新保留原安装类型

普通 npm 插件通过 DSH 官方管理器按精确版本更新，保留 npm 安装规格及官方后续版本管理资格，不再因为我们的普通更新流程变成本地归档安装。

更新失败和旧版恢复分别显示：**恢复成功不等于升级成功**。丢失结果或无法核验的状态保持“未知”，不会自动重发更新或恢复请求。

### 保留合法停用状态与迁移身份

- 普通更新／恢复及WSL代际后验区分“整个bundle停用”“个别条目停用”和实际加载失败。停用但仍运行、错误条目身份、已启用条目加载失败仍拒绝，不制造Host active。
- 未开始替换的迁移在取消／重新初始化或跳过后保留已识别原归档身份，不依赖旧诊断历史尚未旋转。
- Union Search当前HMR路径及身份记录不可核验时，恢复入口也与执行层拒绝条件一致。

### 旧归档有独立迁回 npm 的入口

仅限能核验为此前更新器创建的普通插件归档。用户单独确认后，从 npm 重新安装**同一版本**，不是升级，也不是自动迁移。

不适用于任意本地包、Git／开发链接、更新器自身或 WSL。失败时可能需要恢复原归档；安装与恢复均可能失败。

### 增加受限制的来源与依赖支持

- 支持 npm 官方源及固定公共镜像 `registry.npmmirror.com`。支持的镜像操作须与官方同版本归档核对，并额外确认来源风险；不会偷偷修改 DSH 的源配置。
- 更新器自身的镜像升级独立确认，绑定已核验的公共来源计划；自身升级不与普通批次混合。
- 普通插件不再仅因声明 JS 依赖就被拒绝。只接受声明不变、解析关系和实际文件可核验、无原生依赖或安装生命周期脚本的受审查路径；不代表所有带依赖插件都能热更新。

### 扩展 WSL 与详情入口

- 在隔离原版 DSH Host 中验证了 WSL `0.26.2 → 0.28.0` 的代际更新及恢复，保留旧资源。
- WSL 仍保存为代际本地归档，**不伪装成 npm 安装，也不恢复宿主内置 Versions 资格**。
- 官方插件详情页增加由本更新器提供的独立归档检查和处理入口。该入口只检查、导航，不直接安装。
- 已有会话可能继续使用旧预设；没有验证所有真实发行版任务或会话无缝切换。需要新预设时建议使用新会话。

## 这次没有解决什么

### Union Search 的安全无重启更新：当前不支持

在原版 DSH Desktop `0.2.2-rc.5` 的隔离验证中，Union Search `0.10.24 → 0.10.25` 热加载失败，自动恢复原旧版也失败。因此开发稿拦截当前 HMR 环境中的 Union Search 更新、来源迁移和恢复，仍可在版本扫描中显示发现结果。

**这是风险拦截，不是热更新修复。** 普通用户仅安装本更新器，不能获得该问题的完整修复。单独修改 Union Search 或底层运行时的研究结果，不属于本插件发布功能；本插件不会修改 DSH 内核、注入调试补丁、强制清缓存或自动重启。

其他插件的成功测试也不能推导为“所有插件都支持无重启更新”。需要重启或单独处理的目标，应使用另行确认、验收的流程。

## 更新前请知道

- 仅支持 **Windows x64**；兼容范围是准入声明，不是所有 DSH 版本均经过实测。
- 默认等待当前任务自然结束。停止任务必须另行明确同意；本插件不杀进程、不强制解锁。
- 更新会影响当前配置的所有会话。本插件不自动退出或重启 DSH。
- 普通 npm 更新由 Host 再次下载，可能沿用它现有的 fallback 和依赖来源。预下载校验是证据，**不是原子替换，也不是同一份归档字节的安装保证**。
- 本地诊断不上传；分享前仍需自行检查脱敏结果。

## 验证到哪一步

已完成源码回归和自有隔离 Host 中的限定成功／失败恢复实验；测试通过范围及显式跳过项见[验证记录](<VERIFICATION.md>)。

**已完成 v0.5.1 本地候选包的资源检查与隔离原版Host安装／限定流程验收；尚未完成用户真实安装升级或新界面的浏览器交互验收。** 不能把源码测试、模拟编排或底层修复研究当作这些真实用户验收已经通过。
