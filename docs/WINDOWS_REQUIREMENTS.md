# Windows运行要求与其他设备安装

适用于独立插件在线更新器。**没有绑定开发者电脑，不等于全部Windows x64设备都经过验证。**

## 必需条件

| 项目 | 条件与核验范围 |
|---|---|
| 平台 | Windows x64。当前包只提供x64文件占用检测助手，不支持Mac；不把Windows ARM64等同x64已验证。 |
| DSH | manifest声明 `>=0.2.2-rc.3 <0.3.0`；最新完整隔离流程和本机实际使用为Desktop `0.2.2-rc.5`。安装兼容范围不是每个版本、每个配置组合实测。 |
| 插件运行时 | **DSH实际执行插件的Node ≥24**，不是仅检查系统PATH里另装的Node。未锁死到24.21.0或Electron44.7.0；这些是实测版本，不是精确版本依赖。 |
| DSH服务 | 官方pluginManager、profileContext、agents及面板使用的Connection／Client扩展必须可用；在线加载还受宿主HMR与生命周期支持约束。裁剪／自定义组合不能当作默认Desktop验收。 |
| 包依赖 | YAML固定2.9.1由官方管理器安装，Host peers由DSH提供；安装和更新由当地DSH的包管理环境执行。 |
| 网络 | 公共原包预检需要访问npm官方源；允许的固定公共镜像需和官方原包比对并额外确认，不静默迁移私有源或更改registry配置。网络超时、TLS／代理／企业网络策略均可能使检查或安装失败。 |
| 文件系统 | 插件和缓存目录可读写，有足够空间保留新旧代。符号链接／junction／网络或设备路径等受有意的信任边界限制；拒绝并不自动说明文件被占用。 |

普通安装用户不需要开发源码、实验结果、全局pnpm、C#编译器或重建DSH。需要的是**安装完整包并让DSH官方管理器处理依赖和安装**；本插件不会自动修复宿主缺失的运行工具，也不会批准脚本、版本豁免、提权或强解锁。

## .NET检测助手：辅助依赖，不是自包含

[只读助手源代码](<../native/LockProbe.cs>)与[构建脚本](<../native/build.ps1>)随包附带，已编译的x64助手也在安装包中。构建脚本使用.NET Framework4工具链并引用System.Web.Extensions，助手需要设备上相应的 **.NET Framework 4.x运行环境**以及执行许可。

- 用户**不需要C#编译器**，也不需要运行构建脚本。
- 一般现代Windows常见此运行环境，但精简系统、企业管理设备或安全策略可能缺失、禁用或拦截助手；未在这些设备逐一验证。
- 助手启动失败、超时或无法访问路径时，文件使用诊断报告**不可用／未知**，不能宣称没有占用。
- 当前执行流程对“实际观测到sharing violation”拒绝替换；诊断未知并不是所有路线的统一硬阻断。因此其他校验通过仍可能进入Host操作，但**不能承诺在缺少诊断时已排除锁故障**。安装仍可能因权限、杀毒软件或外部占用失败。
- 助手只读取元数据和Restart Manager文件使用列表；不会关闭用户进程、释放外部句柄或改变ACL。只允许结束本次诊断自己启动的助手。

## 不依赖开发者机器

已核验的安装归档检查：未携带开发者用户名、C盘开发目录、GUI端口、PID或实验目录；不含实验／测试／用户配置／stage缓存。运行路径从宿主profile、安装锚点以及包内相对资源取得。

固定的**公开registry、精确依赖版本、已审查原包摘要、WSL声明契约、Union升级对和资源上限**属于产品安全策略，不是某台电脑的环境地址。这些策略仍可能让结构或来源不同的目标被拒绝，不能称为任意插件均可更新。

## 给另一台设备的建议

1. 通过那台设备的DSH官方管理器安装 `dsh-plugin-update-doctor`，由管理器实际查询版本并核对兼容性；不要复制开发者profile、stage缓存或原机器保存的绝对安装来源。
2. 如果选择本地归档安装，将归档放在当地稳定可读的目录，后续管理可能需要该本地源；本地来源不支持自身升级。不要求与原机器相同盘符或用户名。
3. 安装后先检查更新器Host激活，再在面板只读检查候选及拒绝原因。新的准入会核验当地的插件版本、来源、资源与声明，不复用原机器通过结果。
4. 只在面板核对目标和任务政策后更新。默认等待，首次宜单项操作，保存真实结果；未知结果不要连续重试。

本机已由用户真实完成WSL `0.26.2 → 0.29.0`，Host16/16active；隔离完整包和恢复路径有单独证据。**第二台物理设备、真实WSL发行版／既有任务连续性，以及所有系统策略组合尚未验证。**

版本由官方管理器实际查询。若旧更新器已经被来源检查阻止，通过官方管理器安装含修复的版本进行一次引导升级；不需要更改全局npm源。发行与归档核验规范见[发行说明](<PUBLICATION.md>)。

## 安装包与文档

使用完整安装包；本地源码、已安装包和新发行归档是不同对象。文档变更需要重新打包并核验新归档，历史验收包不被覆盖。安装说明不写死npm标签的即时状态。
