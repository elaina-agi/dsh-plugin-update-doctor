# v0.5.10：停止任务不再要求第二次勾选

日期：2026-11-25（Asia/Shanghai）

## 改动

确认弹窗里原本在「停止当前智能体任务后更新」下方还有一个独立勾选框：

> 我明确同意停止当前配置所有运行中的智能体任务并清除排队输入。我已保存工作，已经完成的操作不能撤销。

现在去掉。选择这个选项本身即为同意，主按钮写作「确认停止任务并更新」，选项旁仍保留影响说明（清除排队输入、已完成的操作不能撤销、新启动的任务只等待、不杀外部终端与独立 Worker）。

**校验没有放宽**：`lib/service.js` 的 `commitBatch` 仍在 `taskPolicy === 'cancel-active'` 时要求 `confirmCancel === true`，只是这个值现在由所选选项直接带出，不再依赖第二个勾选。

## 验证

- 完整回归：**411 项通过、0 失败、0 跳过**（串行）。
- 交互断言：停止选项无第二勾选；确认按钮在停止语义下文案不同；提交时携带 `confirmCancel: true`。
- 真实结果：本机 profile 已通过 0.5.9 路线完成 WSL `0.29.0 → 0.29.1`，记录为 `updated`、包核验 verified、宿主 **16/16 active**。
